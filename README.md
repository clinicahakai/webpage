# HAKAI Clinica Dental

Sitio web institucional responsive para HAKAI Clinica Dental, clinica odontologica ubicada en Quilpue, Chile.

## Descripcion

Este proyecto corresponde a una landing page estatica orientada a presentar los servicios, especialidades, informacion institucional, convenios y canales de contacto de la clinica.

El sitio esta desarrollado con HTML, CSS y JavaScript puro, priorizando carga rapida, navegacion simple y adaptacion a dispositivos moviles.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Remix Icon
- Google Fonts

## Estructura

```text
.
├── assets/
├── css/
│   └── styles.css
├── js/
│   └── script.js
└── index.html
```

## Caracteristicas

- Diseno responsive para desktop y mobile.
- Navegacion tipo SPA mediante hash routes.
- Navbar fijo con identidad visual HAKAI.
- Secciones de especialidades, nosotros, convenios y contacto.
- Integracion con enlace externo de agenda online.
- Boton flotante e interaccion via WhatsApp.
- Paleta visual basada en azul noche, dorado y turquesa.

## Vista Local

Abre el archivo `index.html` directamente en el navegador.

Tambien puedes usar una extension como Live Server en VS Code.
